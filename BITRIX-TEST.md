# Тестовая статья внутри сайта Битрикс

Опубликована по адресу https://dev.topengineer.ru/test/. Встроен вариант с фоновой фотографией, четырьмя курсами, актуальным рублёвым калькулятором и всеми последующими блоками. Шапку, меню и подвал отдаёт сам сайт Битрикс.

## Как устроена изоляция

`src/embedded/main.jsx` загружает только `ReferenceCourse` и помещает его в Shadow DOM элемента `<te-training-test>`. CSS статьи находится внутри этого дерева и не оформляет соседние элементы сайта. Шрифты получают отдельные названия, чтобы их регистрация не заменяла шрифты оболочки. Общая оболочка самостоятельного прототипа сюда не включается.

Ссылки переходят к разделам внутри статьи и сохраняют путь `/test/`. Обработчик кнопки заказа общей шапки не подключается. Окна расчёта и изображений используют штатный `dialog`; во время открытия временно блокируют прокрутку и восстанавливают её при закрытии. Это изоляция оформления и взаимодействий, а не защита от недоверенного JavaScript: код выполняется в том же браузерном документе.

## Сборка на другом компьютере

В отдельной копии репозитория с Node.js 24:

```sh
npm ci
npm run check
npm run build:test-body
```

Результат:

- `dist/bitrix-test/te-tekla-20261030/` — скрипт, стили, фотографии, обложки, сертификаты и шрифты;
- `dist/bitrix-test/body-snippet.html` — фрагмент для тела статьи;
- `dist/bitrix-test/deployment.json` — версия и префикс ресурсов.

Сборка также копирует ресурсы в `dist/client/test/` для локальной проверки. Обычный `npm run build` пересоздаёт `dist/client`, поэтому специальную сборку запускайте после обычной. Пароли, SSH-ключи, Python и исходный сервер 8774 для сборки не нужны.

## Размещение администратором

1. Проверьте домен и корневую папку сайта в настройке веб-сервера. На проверенном сервере корень — `/var/www/clients/client1/web1/web`, файл страницы — `test/index.php`.
2. Сохраните исходный `test/index.php` вне публичной папки вместе с владельцем и правами. Перед перезаписью убедитесь, что его никто не изменил после создания копии.
3. Для нового обновления задайте новый `version` в `scripts/build-test-body.mjs` и пересоберите пакет. Загрузите полученную папку ресурсов в `/test/` под тем же именем. Так браузер не возьмёт предыдущий скрипт из своего кеша.
4. Замените только содержимое статьи между подключениями `/bitrix/header.php` и `/bitrix/footer.php` на содержимое `body-snippet.html`. Сохраните существующие PHP-подключения, настройки и оболочку. Не заменяйте файл страницей `dist/client/index.html` и не загружайте целый самостоятельный сайт поверх Битрикс.
5. Проверьте PHP командой `php -l` для подготовленного файла, сохраните владельца/права и замените файл атомарно. Для опубликованной версии использованы `web1:client1`, каталоги 0755, файлы 0644.
6. Если обычный `/test/` показывает старую заглушку, а адрес с проверочным параметром — новую статью, сохраните и удалите только готовые HTML-файлы композитного кеша этой страницы. Проверенная папка: `bitrix/html_pages/dev.topengineer.ru/test/`. Глобальный кеш и настройки сайта менять не требуется.
7. Проверьте именно обычный https://dev.topengineer.ru/test/: целое изображение без обрезки голов, четыре курса, девять строк обзора, калькулятор, окна, внутренние переходы и телефонную ширину. Первый блок следует высоте текста/таблицы с запасом 15%. Сверьте шапку и подвал с исходным состоянием.

Сама команда сборки ничего на сервер не отправляет. Доступ к серверу передаётся отдельно; учётные данные нельзя сохранять в исходниках, журнале развёртывания или Git.

## Опубликованная версия и возврат

Текущая версия ресурсов: `/test/te-tekla-20261030/`. Обновление 30 октября изменило в PHP только адрес скрипта. Предыдущая рабочая версия сохранена в `/root/topengineer-test-deploy-20261030-compact/index.php.before`; её можно восстановить для возврата к первому экрану от 29 октября. В этой же закрытой папке сохранён прежний кеш страницы. Проверка синтаксиса PHP прошла.

При первоначальной публикации 29 октября заменена только заглушка `Text here....`; PHP до и после неё остался побайтно тем же.

Резервная копия исходной страницы на сервере: `/root/topengineer-test-deploy-20261029-ae94783/index.php.before`. В этой же закрытой папке находятся сведения о размещении и сохранённые HTML-файлы прежнего кеша `/test/`.

Для возврата восстановите эту копию как `test/index.php`, сохранив владельца и права. Затем обновите только композитный кеш `/test/`, чтобы он не продолжал показывать новую статью. Папку ресурсов можно временно оставить: после возврата страницы она не подключается. Шапку, подвал, другие страницы, настройки веб-сервера и сервисы для возврата менять не нужно.
