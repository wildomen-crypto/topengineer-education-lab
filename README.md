# Обучение Tekla Structures — Topengineer

Отдельный публичный проект: [wildomen-crypto/topengineer-education-lab](https://github.com/wildomen-crypto/topengineer-education-lab).

Страница обучения имеет две композиции первого экрана: утверждённую с отдельной фотографией и новую с фотографией на весь экран, текстом и таблицей поверх неё. Остальные 22 прежних варианта, галереи и панели переключения удалены по просьбе пользователя. Сохранены фирменные шапка, меню и подвал. В меню «Учебный центр» находятся две обычные ссылки на эти композиции.

Основная страница: http://127.0.0.1:4173/education-centr/tekla-23-site-style/

Первый экран с фоновой фотографией: http://127.0.0.1:4173/education-centr/tekla-photo-hero/

В новом варианте изображение из предоставленного примера заполняет начало страницы, слева находится текст, справа — полная таблица на тёмной подложке. Подробное вводное описание раскрывается по нажатию. На телефоне текст и таблица расположены друг под другом. Все последующие блоки, цены и программы общие для обеих композиций. Оформление нового первого экрана — `src/reference/photo-hero.css`; проверка — `qa/2026-10-29-photo-hero/`.

Старые локальные ссылки на варианты и галереи открывают эту страницу. Адрес сохранён, чтобы существующие закладки продолжали работать.

## Запуск

Нужен Node.js 24. Инструкция для другого компьютера и готовое задание Codex — [DEPLOYMENT.md](DEPLOYMENT.md).

```sh
npm ci
npm run check
npm start
```

В Windows можно открыть страницу с фоновым сервером:

```powershell
powershell -ExecutionPolicy Bypass -File .\Open-Preview.ps1
```

Для разработки — `npm run dev`. Готовая сборка находится в `dist/client`. Исходный сервер 8774, API-ключи, Python и база данных не нужны.

## Содержимое страницы

- «Коротко о курсе» включает все 12 пунктов предоставленного образца: программу и версию Tekla, дни и часы, форматы и онлайн-связь, начало, участников, подготовку, языки, оплату и переход к расчёту. Языки обучения по уточнению пользователя — русский, английский и испанский. Длительности и часы связаны с данными остальных блоков.
- Четыре курса: базовый, пользовательские компоненты, продвинутая работа, настройка системы и создание шаблонов. По 88 тем в каждом, две части по 44 темы. Полные программы переключаются вкладками, разделы можно сворачивать.
- Выбор курса по всей площади карточки, отдельная кнопка полной программы и заметные состояния наведения/фокуса.
- Компактный калькулятор: индивидуальные место занятий, длительность, участники и дата для каждого курса. Длительности — 2/5/10 дней, по 8 часов в день.
- Процесс обучения, книги, длительности с раскрываемыми подробностями, место занятий, подготовка, сертификаты и поддержка после курса.
- Книги и сертификаты адаптивно перекрываются при сужении колонки; изображения открываются крупно.
- Основной язык руководства — русский; доступны также английский, испанский и китайский, другие языки — по запросу. Описание, калькулятор, заявка и подготовленное письмо используют общие сведения о книге.
- Поиск в шапке находит разделы текущей страницы. Кнопка «Заказать» открывает обращение с выбранными условиями. Письмо отправляет пользователь из своего почтового приложения.

Цвета и шрифты взяты с нового сайта: `#ffc34e`, `#16222d`, `#ecf0f4`, Archivo и Roboto. Ширина контента соответствует измеренным контейнерам dev.topengineer.ru, фоны заполняют экран. Основные блоки автоматически чередуют белый и светло-серый фон.

## Цены

Цены в рублях по предоставленным таблицам и последним уточнениям пользователя. Для 5/10 дней группа из 1–5 человек оплачивается по единой ставке: онлайн/офис — 220 000 / 440 000 ₽, с выездом — 280 000 / 560 000 ₽. От 6 участников применяются опубликованные ставки. Двухдневный онлайн-прайс сохранён; выезд на 2 дня согласуется отдельно. Десятидневные тарифы вдвое выше пятидневных. Электронный комплект из трёх книг — 8 000 ₽. Стоимости выбранных курсов суммируются без пакетной скидки; даты считаются включительно по календарным дням.

## Основные файлы

- `src/App.jsx` — утверждённая оболочка, ссылка курса в меню, поиск разделов и старые адреса.
- `src/reference/ReferenceCourse.jsx` — страница и взаимодействия.
- `src/reference/courses.js`, `ReferenceProgram.jsx`, `programmes.css` — четыре программы, вкладки и темы.
- `src/reference/pricing.js`, `rates.json`, `book-product.json` — общие расчёты и цены.
- `src/reference/durations.js`, `duration.css` — сопоставимые описания длительностей и полные подробности.
- `src/reference/MediaGallery.jsx`, `media-gallery.css` — книги, сертификаты и увеличенный просмотр.
- `src/reference/site-width.css` — ширина по правилам нового сайта.
- `src/data/shell.json`, `public/assets/` — сохранённая оболочка и локальные ресурсы.
- `qa/`, `design-qa.md` — проверки и снимки. Исторические макеты и отчёты не являются страницами приложения.

Скрипт `prepare-source.py` — исторический импортёр; повторно запускать его не нужно. Не восстанавливайте удалённые варианты из старых отчётов. Постоянные решения проекта записаны в `AGENTS.md`.

## Проверки

`npm run check` собирает сайт и выполняет 9 проверок цен/дат и 4 проверки размещения. Актуальная визуальная проверка — `design-qa.md`. Проверка удаления старых вариантов и галерей сохранена в `qa/2026-10-29-single-course/`; она не запрещает новую композицию, добавленную по следующему запросу пользователя.
