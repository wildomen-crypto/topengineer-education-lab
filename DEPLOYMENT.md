# Запуск на другом компьютере и передача проекта Codex

Репозиторий: https://github.com/wildomen-crypto/topengineer-education-lab (публичный).

Это самостоятельный сайт на React и Vite. Страница обучения Tekla Structures с четырьмя курсами имеет две композиции первого экрана: основную и дополнительную с фоновой фотографией. Их исходники, изображения, шрифты, цены и программы находятся в репозитории. Прежние 22 варианта и галереи удалены из приложения; старые локальные ссылки открывают основную страницу.

Для обычного запуска нужны **Git и Node.js 24.x с npm**. Версия Node записана в `.nvmrc`; проверено на Node 24.14.1. База данных, Python, API-ключи, старый компьютер и сервер `127.0.0.1:8774` не требуются.

## Получить проект

Для просмотра и скачивания проекта вход в GitHub не нужен. Склонируйте проект:

```sh
git clone https://github.com/wildomen-crypto/topengineer-education-lab.git
cd topengineer-education-lab
```

Откройте полученную папку `topengineer-education-lab` как проект в Codex.

В терминале этой папки выполните:

```sh
node --version
npm ci
npm run check
npm start
```

`npm ci` ставит версии из сохранённого списка зависимостей. `npm run check` собирает сайт и проверяет рублёвые расчёты, маршруты и комплект сборки. `npm start` открывает локальный сервер готового сайта. Оставьте этот терминал работающим; остановка — `Ctrl+C`.

Открыть в браузере:

- Основная страница: http://127.0.0.1:4173/education-centr/tekla-23-site-style/
- Первый экран с фотографией: http://127.0.0.1:4173/education-centr/tekla-photo-hero/

## Повторное открытие после перезагрузки

На Windows можно запустить из папки проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\Open-Preview.ps1
```

Этот локальный скрипт устанавливает отсутствующие зависимости, пересобирает сайт, запускает сервер в фоне и открывает утверждённую страницу. Он использует Node.js, без Python. Если сервер этой копии уже работает, скрипт использует его повторно. Его сообщения сохраняются в `.preview-server.stdout.log` и `.preview-server.stderr.log`; эти файлы не отправляются в Git.

При занятом порте другим сайтом укажите другой порт:

```powershell
powershell -ExecutionPolicy Bypass -File .\Open-Preview.ps1 -Port 4174
```

На macOS/Linux либо при работе из терминала достаточно `npm start`. Для другого порта: `npm start -- --port 4174`.

## Продолжить разработку

Вместо просмотра сборки запустите:

```sh
npm run dev
```

Адрес остаётся `http://127.0.0.1:4173`. Сервер разработки обновляет страницу при сохранении исходников. Одновременно запускайте один сервер на этом порте. После изменения кода для готового просмотра снова выполните `npm run check`, затем `npm start`.

Обновление проекта с GitHub:

```sh
git pull --ff-only
npm ci
npm run check
npm start
```

Перед обновлением сохраните свою работу отдельным коммитом; не используйте принудительный сброс изменений. Если ветки разошлись, сначала разберите различия.

## Готовое задание Codex на другом ПК

Передайте Codex ссылку на этот репозиторий и следующее задание:

> Склонируй https://github.com/wildomen-crypto/topengineer-education-lab.git в отдельную папку или используй уже открытую копию этого репозитория. Прочитай AGENTS.md, DEPLOYMENT.md и README.md. Разверни существующий проект без изменения дизайна: проверь Node.js 24, выполни npm ci и npm run check, запусти сайт на 127.0.0.1:4173 и открой /education-centr/tekla-23-site-style/. На Windows можно использовать Open-Preview.ps1 для фонового запуска. Не останавливай чужой сервер, если порт занят: выбери свободный и сообщи адрес. Проверь загрузку изображения, фирменных шрифтов, четырёх курсов и рублёвого калькулятора. Сохрани утверждённые шапку, футер и текущие цены. Сохрани также добавленный по следующему запросу вариант первого экрана с фотографией по адресу /education-centr/tekla-photo-hero/. Не восстанавливай удалённые прежние 22 варианта и галереи. Контент и ресурсы уже включены: исходный сервер 8774 и файлы прежнего компьютера для запуска не нужны. Объясни результат простыми словами и дай рабочую локальную ссылку.

Codex читает проектный `AGENTS.md` как постоянные инструкции. Размещение и назначение файла описаны в [официальной документации OpenAI](https://learn.chatgpt.com/docs/agent-configuration/agents-md).

## Что редактировать

- `src/reference/ReferenceCourse.jsx` — основная страница 23 и взаимодействия.
- `src/reference/site-width.css` — ширина контента по правилам нового сайта.
- `src/reference/pricing.js`, `rates.json`, `book-product.json` — расчёт, тарифы и книги.
- `src/reference/courses.js` — четыре курса и полные программы.
- `public/assets/reference/` — фотографии, обложки и сертификаты.
- `src/App.jsx` — общая оболочка, один пункт курса в меню, поиск разделов и обработка старых ссылок.
- `src/data/shell.json` и сохранённые стили в `public/assets/` — утверждённая оболочка.
- `qa/` и `design-qa.md` — сохранённые проверки и изображения.

Обычная сборка использует готовые ресурсы из `public/`; заново скачивать исходный сайт или генерировать изображения не нужно. Скрипты `compare-*.mjs` обрабатывают уже сохранённые снимки; для них включена зависимость `sharp`. `prepare-source.py` — исторический импортёр архивов источника; для развёртывания его запускать не надо.

## Размещение готового сайта на хостинге

`npm run build` создаёт статический сайт в `dist/client`. Для веб-сервера задайте эту папку корнем сайта и перенаправляйте неизвестные HTML-маршруты на `/index.html`, чтобы прямая ссылка на страницу открывалась после перезагрузки. Существующие файлы должны отдаваться напрямую. Проект рассчитан на корень домена; путь вида `github.io/имя-репозитория/` требует отдельной настройки адресов ресурсов.

`dist/server/index.js` и `dist/.openai/hosting.json` — дополнительный комплект для совместимого размещения Sites. Публикация репозитория на GitHub сама по себе не развёртывает сайт на внешнем хостинге.
