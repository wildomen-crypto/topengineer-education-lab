# Prototype Instructions

## Standalone checkout and another computer

Read `DEPLOYMENT.md` and `README.md` before bootstrapping this project. The whole site is self-contained in this repository; Node.js 24 and npm are the normal requirements. Run `npm ci`, `npm run check`, then `npm start` (127.0.0.1:4173). On Windows `Open-Preview.ps1` builds, starts a hidden preview and opens variant 23 without requiring Python. Keep the server running and return the local URL. If the port belongs to another app, choose another port instead of stopping that process.

The only working course page is `/education-centr/tekla-23-site-style/`. The former variants and mockup gallery were removed at the user's request; their old local URLs resolve to the retained page. Do not restore the comparison gallery or variant navigation. The user requested a separate GitHub project, unrelated to the parent Tekla component-editor repository. Work and commit only in this site's own Git root; use `codex/` for feature branches.

Use the checked-in `public/` assets and current `src/reference/` data. The old server on port 8774 and paths in historical QA notes are provenance, not runtime dependencies. Do not rerun the original source importer or regenerate imagery when deploying. The earlier EUR instruction below is historical and explicitly superseded by the current RUB tables and 8,000 ₽ book price. The latest width directive below supersedes the earlier edge-to-edge requirement for variant 23.

`npm run check` runs the build, pricing tests and existing hosting tests. For small copy/style changes, build and inspect the affected layout; do not add tests that just repeat the implementation. Keep `.openai/hosting.json`, `worker/index.js`, `scripts/prepare-sites-build.mjs` and `tests/sites-worker.test.mjs` intact. Build output, dependencies, local logs and credentials are ignored by Git; never commit `.env` files or access tokens.
